        CONNECT YOUR AI

        ใช้ SIR OCR ผ่าน MCP

        ให้ AI อัปโหลด PDF ติดตามงาน และอ่านข้อความทีละหน้าได้จากโปรแกรมที่คุณใช้

        1. สร้าง token ของคุณ

          เข้าสู่ระบบที่ SIR Account → Tokens ↗ แล้วสร้าง token ที่ขึ้นต้นด้วย sirpat_

        2. เลือกโปรแกรม แล้วคัดลอกไปติดตั้ง

          ต้องติดตั้งโปรแกรมนั้นก่อน สำหรับ CLI ใช้ Terminal แบบ Bash / Zsh บน macOS, Linux หรือ WSL และแทน sirpat_REPLACE_ME ด้วย token ของคุณก่อนรัน

          รันคำสั่งนี้ แล้วเปิด Claude Code ใหม่

          export SIR_PAT='sirpat_REPLACE_ME'
claude mcp add --transport http --scope user sir-ocr https://mcp.sir-labs.com/mcp --header "Authorization: Bearer $SIR_PAT"

        3. สั่ง AI ให้เริ่มอ่านเอกสาร

          ใช้ sir-ocr อ่าน PDF /path/to/paper.pdf แล้วสรุปให้หน่อย

          AI จะอัปโหลดไฟล์จากเครื่องของคุณ แล้วใช้ ocr_status และ ocr_read เพื่อติดตามและอ่านผล รองรับ PDF ไม่เกิน 50 MiB / 500 หน้า และอ่านหน้าที่เสร็จแล้วได้ทันที

        ข้อมูลการเชื่อมต่อและเครื่องมือ

        URL: https://mcp.sir-labs.com/mcp
        Transport: Streamable HTTP
        Header: Authorization: Bearer <SIR token>

        ocr_upload_instructions วิธีอัปโหลด · ocr_list รายการงาน · ocr_status สถานะ · ocr_read Markdown รายหน้า · ocr_cancel ยกเลิกงาน

        ต้องใช้ client ที่ส่ง Authorization header ได้ ผลจาก MCP เป็นข้อความ Markdown และยังไม่รวมการดึงภาพประกอบ
